# Ansh Bridal Mehandi Art 🌿✨

Official website for **Ansh Bridal Mehandi Art** — Luxury Indian Bridal Mehendi Artist in Greater Noida & Delhi NCR with 11+ years of experience.

- **Palette**: Royal Blue (`#0B1E3D`), Deep Blue (`#061021`), Creamy White (`#FAF8F5`), and Elegant Gold (`#D4AF37`)
- **Typography**: Cinzel, Cormorant Garamond, and Plus Jakarta Sans

## 🛠️ Tech Stack
- **Framework**: React 19 & TypeScript
- **Bundler**: Vite 8 with relative asset resolution (`base: './'`)
- **Styling**: Tailwind CSS v4 with custom royal blue & gold accents
- **Icons**: Lucide React
- **Deployment**: Configured for GitHub Pages via GitHub Actions (`.github/workflows/deploy.yml`)

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
The compiled, production-ready static assets are generated in the `dist/` directory with relative asset paths, ready for deployment on GitHub Pages or any static host.

## 🌐 Deploy to GitHub Pages

### Option A: Automatic Deployment (Recommended via GitHub Actions)
1. In your GitHub repository, navigate to **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Push changes to the `main` branch. The included workflow (`.github/workflows/deploy.yml`) will automatically build and publish your website.

### Option B: Deploy from Branch
1. Run `npm run build`.
2. Deploy the contents of the `dist/` directory to the `gh-pages` branch.
